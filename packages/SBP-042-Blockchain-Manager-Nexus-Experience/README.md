# SBP-042 — Blockchain Manager Nexus Experience

Pure frontend UX package.

Goals:
- Put installed/live blockchains first.
- Make the active BCH runtime the operational focal point.
- Replace catalog-oriented summary counts with operator-oriented runtime KPIs.
- Keep future providers visible but visually quieter.
- Make the overall page feel like a Nexus module instead of an app-store catalog.
- Preserve the canonical runtime-state presentation and SBP-041 stabilization behavior.

This package does not alter backend runtime state, lifecycle policy, or API behavior.
