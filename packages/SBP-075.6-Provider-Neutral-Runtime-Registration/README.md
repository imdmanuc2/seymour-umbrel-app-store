# SBP-075.6 — Provider-Neutral Runtime Registration

Replaces the BCH-only Nexus registration projection with canonical
runtime-binding enumeration.

Managed blockchain runtimes are registered from persisted runtime
bindings and authoritative Umbrel native lifecycle state.

The package preserves:
- stable Manager identity
- stable runtime asset identity
- existing registration identity
- BCH rich telemetry
- managed-runtime registration contract 1.0
- compatibility with legacy BCH runtime bindings
