# SBP-001 — Bitcoin Cash Node Foundation

Replaces the BCH nginx placeholder with a persistent Bitcoin Cash Node app foundation, status service, service contract, and provisioning definitions.

```bash
chmod +x scripts/*.sh
./scripts/doctor.sh
./scripts/install.sh
./scripts/verify.sh
```

This package changes App Store source only. It does not install the Umbrel app, start containers, sync a blockchain, or modify the host.
