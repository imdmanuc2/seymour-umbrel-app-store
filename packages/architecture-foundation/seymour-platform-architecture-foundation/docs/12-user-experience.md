# Recommended and Advanced Setup

## Recommended setup

Seymour chooses the tested implementation, release, profile, provisioning method, storage layout, networking, and update policy.

The user supplies only information Seymour cannot safely infer, such as wallet addresses and administrative credentials.

## Advanced setup

Advanced users may select:

- network
- node implementation
- software version
- consensus or policy profile
- provisioning method
- storage location
- ports and networking
- remote service endpoints

## Design principle

Simple things should be simple. Complex things should be possible.
