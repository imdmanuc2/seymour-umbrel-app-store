# Product Catalog and Ownership

## Seymour Platform Installer

Owns lifecycle orchestration, planning, capability validation, operations, evidence, retry, resume, transactions, rollback, and health gates.

## Seymour Blockchain Platform

Owns blockchain node implementations, chain data, RPC, ZMQ, provisioning, synchronization, backup, restore, copy, verification, and blockchain service contracts.

Initial Version 1.0 implementations:

- Bitcoin Core
- Bitcoin Cash Node

## Seymour Mining Platform

Owns managed mining applications that depend on healthy blockchain services, including Seymour MiningCore.

## Seymour Pool Platform

Owns native and integrated pool engines, including Seymour Pool Engine and supported CKPool deployments.

## Nexus Command Center

Owns discovery, CMDB, topology, observability, operations, evidence presentation, recommendations, alerts, and human-facing orchestration.

Nexus does not own another product's private runtime state.
