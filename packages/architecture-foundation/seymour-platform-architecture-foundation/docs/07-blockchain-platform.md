# Blockchain Platform

## Version 1.0 scope

- Bitcoin Core
- Bitcoin Cash Node
- local persistent chain storage
- RPC and ZMQ
- synchronization monitoring
- health verification
- backup and restore
- copy from an existing trusted node
- remote-node connection option
- service contract publication
- Nexus registration

## Provisioning choices

- synchronize from peers
- copy from an existing Seymour node
- restore a verified Seymour backup
- connect to an existing remote node

## User modes

Recommended mode selects Seymour-certified implementations, versions, storage, networking, and update policy.

Advanced mode exposes implementation, software version, network, consensus profile, provisioning method, storage path, ports, and resource settings.

## Identity model

A node deployment is identified by network, implementation, version, and profile—not only by a ticker symbol.
