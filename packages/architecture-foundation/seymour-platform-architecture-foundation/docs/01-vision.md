# Vision

Seymour lets an operator describe the mining infrastructure they want to build rather than forcing them to assemble and configure every technical dependency manually.

## Product promise

A new operator should be able to choose a supported outcome such as:

- Bitcoin solo pool
- Bitcoin Cash solo pool
- public mining pool
- complete mining platform

Seymour then plans, provisions, configures, verifies, registers, and operates the required components.

## Version 1.0 outcome

Version 1.0 must deliver a complete production workflow from a fresh supported host to a healthy mining platform that can be observed and operated through Nexus Command Center.
